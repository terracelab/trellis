# 문구

화면에 들어가는 말의 규칙입니다. 버튼 이름, 상태 어휘, 숫자 표기, 메시지 형태를 고정해 어느 모듈에서나 같은 말이 나오게 합니다. 전체 규격은 레포의 `docs/spec/content.md`에 있습니다.

## 세 가지 성격

| 성격 | 뜻 | 예 |
| --- | --- | --- |
| 정확하다 | 현장에서 쓰는 이름을 그대로 씁니다. 숫자는 실제 값입니다 | 11월 부가세 예정신고 마감 11월 25일 |
| 짧다 | 한 문장에 한 가지. 제목은 20자 안쪽 | 결재 대기 12건 |
| 평서문이다 | 설명하지 설득하지 않습니다. 느낌표 · 수식어 · 은유를 쓰지 않습니다 | 표로 볼 수 있습니다 |

문체는 합니다체입니다. 해요체는 쓰지 않습니다. 버튼 · 메뉴 · 라벨은 명사나 동사 어간으로 끝냅니다(저장 · 결재 요청 · 거래처).

## 쓰지 않는 것

- 수식어: 손쉽게 · 간편하게 · 강력한 · 완벽한 · 혁신 · 매끄러운 · 직관적 · 스마트한 · 최적화된 · 놀라운 · 최고의
- 느낌표, 이모지, 인사말 제목. 홈 제목은 날짜나 맥락입니다(11월 7일(금) · 본사)
- 제목 안의 쉼표 · 콜론 · 줄표. 문장을 둘로 나눕니다
- 은유. Trellis라는 이름의 뜻풀이는 소개 페이지에서 한 번만 합니다
- 수를 적을 수 있는데 "다양한 · 수많은"이라고 쓰는 것

## 버튼과 메시지

| 자리 | 규칙 | 예 |
| --- | --- | --- |
| 버튼 | 동사 어간 또는 명사. 2~5자 | 저장 · 취소 · 삭제 · 등록 · 검색 |
| 확인 대화상자의 버튼 | 결과를 말합니다. "예 · 확인"은 쓰지 않습니다 | 삭제 · 반려 · 회수 |
| 등록 · 추가 · 작성 | 마스터 데이터는 등록, 목록 항목은 추가, 문서는 작성 | 거래처 등록 · 품목 추가 · 기안 작성 |
| 수정 · 삭제 | 편집 · 제거 · 지우기 대신 | 수정 · 삭제 |
| 폼 라벨 | 명사, 콜론 없음. 필수는 점 표시 | 거래처 · 공급가액 |
| 플레이스홀더 | 예시 값만. 라벨 대신 쓰지 않습니다 | 123-45-67890 |
| 빈 상태 | 무엇이 없는지 + 다음 행동 | 이번 달 전표가 없습니다. 전표 입력에서 추가하세요 |
| 오류 | 무엇이 틀렸고 어떻게 고치는지. 사과하지 않습니다 | 사업자등록번호는 10자리입니다 |
| 토스트 | 과거형 한 문장 | 저장했습니다 |
| 알림 카드 | 모듈 타일 + 상태 한 줄 + 숫자 하나 | 결재 대기 12건 |
| 결재 올리기 | 버튼은 "결재 요청", 상태는 기안 · 진행 · 승인 · 반려 · 회수 | |

## 숫자 · 날짜

| 음수 | −1,234원(U+2212). 괄호 표기 안 함 | `formatAmount` |
| 큰 금액 요약 | 8.7억. KPI 보조 표기에만 | `formatCompactWon` |

| 수량 | 12건 · 3.5kg · 240EA | (트랙 E에서 `formatQuantity` 제공) |
| 증감 | 전월 대비 +12.4%. 부호 항상 | `formatAmount(v, { sign: 'always' })` |
| 날짜(표 · 입력) | 2026-11-07 | |
| 날짜(문장) | 11월 7일(금) | |
| 기간 | 2026-11-01~11-30. 물결 양쪽 공백 없음 | |
| 시각 | 09:00 · 18:30 | |
| 상대 시간 | 3일 전. 7일이 넘으면 날짜 | |
