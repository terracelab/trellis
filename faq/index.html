자주 묻는 질문

Trellis가 무엇이고 어떻게 쓰는지 짧게 답합니다.

Trellis는 무엇입니까?

Trellis(트렐리스)는 테라스랩의 디자인 시스템입니다. 한국 업무 화면에 쓰는 토큰 · 컴포넌트 · 화면 블록 · 에이전트용 문서를 한 곳에서 관리합니다. 코드의 토큰이 유일한 원본이고 웹 · 데스크톱 · 모바일 화면은 그 생성물입니다.

무엇이 들어 있습니까?

토큰 433개 · 컴포넌트 121종 · 화면 블록 76개가 들어 있습니다. 아이콘 173개와 회사 테마 프리셋 9개도 함께 씁니다. 컴포넌트와 화면 블록은 각각의 페이지에서 볼 수 있습니다.

Trellis와 테라스원은 어떤 관계입니까?

테라스원은 테라스랩이 고객사마다 맞춰 구축하는 업무 플랫폼입니다. 테라스원의 화면은 Trellis의 컴포넌트와 화면 블록으로 만듭니다. 데모가 그렇게 조립한 화면입니다.

어떤 플랫폼에서 쓸 수 있습니까?

지금은 웹에서 React 컴포넌트로 씁니다. 토큰은 CSS 변수와 TypeScript 객체로 나오고 Tailwind v4와 React Native 테마도 같은 토큰에서 만듭니다. Expo 컴포넌트와 Django 패키지는 1.0 뒤에 냅니다.

한국 업무 관습은 어떻게 반영했습니까?

수입은 빨강이고 지출은 파랑입니다. 결재 상태는 다섯 가지 어휘로 고정했습니다. 금액은 원 단위로 쓰고 천 단위로 끊어 오른쪽에 맞춥니다. 자세한 규칙은 원칙과 규칙에 있습니다.

회사 색은 어떻게 바꿉니까?

회사 색 하나를 정하면 테마 엔진이 라이트 · 다크 · 고대비 모드의 회사 색 토큰 21개를 계산합니다. 대비가 모자라면 같은 색상 안에서 단계를 옮겨 맞춥니다. 상태 · 수입 · 지출 · 결재 색은 회사 색이 바뀌어도 그대로입니다. 테마 페이지에서 직접 골라 볼 수 있습니다.

다크 모드를 지원합니까?

지원합니다. 색 토큰마다 라이트 값과 다크 값이 있고 <html data-theme> 속성 하나로 바꿉니다. 컴포넌트 코드는 그대로입니다.

AI 에이전트로 개발할 때 쓸 문서가 있습니까?

있습니다. 문서가 패키지 안에 들어 있어서 설치한 버전과 같은 내용을 인터넷 없이 읽을 수 있습니다. manifest.json · llms.txt · 컴포넌트별 문서로 되어 있습니다. llms.txt와 에이전트로 개발하기에서 시작합니다.

오프라인에서도 쓸 수 있습니까?

쓸 수 있습니다. 글꼴(Pretendard Variable)과 아이콘을 패키지에 넣었고 외부 네트워크를 부르지 않습니다. 설치형 앱에서도 같은 모양으로 그려집니다.

접근성은 어디까지 지킵니까?

텍스트 대비 4.5:1 이상, 모든 조작을 키보드로, 포커스 링 항상 표시를 기본으로 지킵니다. 움직임 줄이기 설정도 따릅니다. 고대비와 포커스 강조 모드가 있고 글자 크기는 112%와 125%로 키울 수 있습니다.

Figma 라이브러리가 있습니까?

있습니다. 코드의 토큰이 원본이고 Figma 파일은 그 생성물입니다. 파일을 열려면 팀 접근 권한이 필요합니다. 구성은 Figma 라이브러리 문서에 있습니다.

버전은 어떻게 올라갑니까?

모든 패키지가 한 버전 번호로 함께 올라갑니다. 토큰 이름과 컴포넌트 props의 변경 · 삭제는 major 버전에서만 합니다. 바뀐 것은 변경 기록에 적고 규칙은 버전 정책에 있습니다.

오픈소스입니까?

오픈소스입니다. 라이선스는 Apache-2.0이고 소스는 GitHub 저장소 terracelab/trellis에 있습니다. 토큰 · 아이콘 · contract · React 컴포넌트는 npm에서 설치합니다. 설치 방법은 문서에 있습니다.

어디서 먼저 써 볼 수 있습니까?

데모에서 화면 블록 76개를 눌러 볼 수 있습니다. 샘플 회사와 샘플 숫자로 그린 화면입니다.
