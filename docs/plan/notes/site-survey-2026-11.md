# 소개 사이트 레퍼런스 조사 (2026-11-12)

PD-10(Trellis 소개 사이트)의 근거다. 공개된 디자인 시스템 소개 사이트 한 곳을 전부 훑어 **구조와 패턴만** 옮겼다.
제품 이름은 적지 않는다(CLAUDE.md). 워드마크 · 일러스트 · 사진 · 문구 · 색은 가져오지 않았다.

## 조사한 것

| 대상 | 방법 |
|---|---|
| 페이지 10종: 홈 · 시작하기 문서 · 컴포넌트 목록 · 템플릿 목록 · 테마 · 플레이그라운드 · 커뮤니티 · CLI 문서 · 변경 기록 · 블로그 | Playwright로 1440×900 · 390×844에서 화면을 나눠 찍고(121장) 본문 글 · 제목 계층 · 버튼 모양을 뽑았다 |
| 홈의 글자 크기 · 간격 · 구역 순서 | 계산된 스타일을 읽었다 |
| 메뉴 · 바닥 링크 · 페이지끼리 잇는 방식 | 링크 목록을 뽑았다 |

캡처와 데이터는 세션 작업 폴더에만 있고 저장소에 넣지 않았다.

## 홈의 구조

| 순서 | 구역 | 패턴 |
|---|---|---|
| 1 | 상단 바 | 왼쪽 표식, 가운데 메뉴 다섯 개(문서 · 컴포넌트 · 템플릿 · 테마 · 플레이그라운드), 오른쪽 아이콘과 시작 버튼. 스크롤하면 반투명 바탕 |
| 2 | 히어로 | 큰 워드마크, 두 줄 제목(첫 줄은 가는 글자 · 둘째 줄은 굵은 글자), 버튼 둘, 상태 한 줄. 양옆에 실제 컴포넌트로 만든 카드가 떠 있다. 아래 점 다섯 개가 테마를 바꾸고 페이지 전체 색이 따라 바뀐다 |
| 3 | 네 칸 | 큰 모서리의 판 위에 왼쪽 큰 제목과 설명, 그 옆으로 칸 네 개(테마 · 컴포넌트 · 에이전트 · 템플릿). 칸마다 제목 · 두 줄 설명 · 화살표 링크 · 살아 있는 견본 |
| 4 | 근거 | 왼쪽에 숫자가 든 큰 문장, 오른쪽에 세 칸(작은 도형 · 제목 · 설명 · 화살표 링크) |
| 5 | 소식 | 큰 글 하나와 작은 글 둘, "전체 보기" 링크 |
| 6 | 마무리 | 둥근 판 가운데 제목과 버튼 둘, 네 귀퉁이에 기울인 화면 그림 |
| 7 | 바닥 | 워드마크 · 링크 한 줄 · 아이콘, 아래 줄에 소속 · 약관 · 저작권 |

치수: 본문 폭 1200, 구역 사이 100, 제목 42 · 35 · 20, 본문 16, 버튼은 알약 모양 36, 칸 모서리 16~24.
휴대폰에서는 히어로 카드가 글 아래 두 칸 격자로 내려오고 네 칸이 한 줄로 쌓인다.

## 다른 페이지의 구조

| 페이지 | 패턴 |
|---|---|
| 컴포넌트 목록 | 왼쪽에 검색과 전체 목록, 가운데 제목과 버튼 둘, 아래로 분류별 구역. 구역마다 세 칸 격자의 미리보기 카드(옅은 바탕 위에 실제 컴포넌트, 아래 이름) |
| 템플릿 목록 | 가운데 제목, 분류 고르기 한 줄, 세 칸 격자의 화면 미리보기 |
| 테마 | 왼쪽 고정 패널(제목 · 설명 · 버튼 둘 · 테마 목록), 오른쪽에 큰 미리보기(상점 · 결제 폼 · 대화 · 표 · 숫자). 테마를 고르면 사이트 전체가 바뀐다 |
| 문서 | 왼쪽 목차, 가운데 본문, 오른쪽 이 페이지 목차. 시작하기 맨 위에 에이전트에게 붙여 넣는 안내문 |
| 플레이그라운드 | 왼쪽 코드 편집기, 오른쪽 실행 결과 |
| 커뮤니티 | 기여자 얼굴, 기여 절차 네 단계, 기여 종류 네 칸 |
| 변경 기록 · 블로그 | 패키지별 탭과 버전 목록, 글 카드 목록 |

## Trellis로 옮긴 것

| 레퍼런스 | Trellis | 다르게 한 것 |
|---|---|---|
| 히어로의 테마 다섯 개 | 회사 색 다섯 개(`THEME_PRESETS`에서) | 색만 바꾼다. 글꼴과 모양은 고정이다(회사 테마의 범위, D-51) |
| 히어로 카드(상점 견본) | 근태 · 질문 입력 · 시재 · 연차 · 알림 카드 | 전부 `packages/react` 컴포넌트를 샘플 값으로 그린다 |
| 히어로 바탕(색 번짐) | 격자 선 | 이름(Trellis)에 맞추고 번짐 효과는 쓰지 않는다 |
| 알약 버튼 | Trellis 버튼 그대로 | 디자인 시스템의 모양을 바꾸지 않는다 |
| 네 칸 | 테마 · 컴포넌트 · 에이전트 · 블록 | 큰 제목은 세 토막 병렬 대신 사실 한 문장(content.md §3) |
| 근거(쓰는 앱 수) | 한국 업무 관습 세 가지(금액 색 · 결재 상태 · 밀도) | 내세울 사용 실적이 아직 없어 원칙을 견본과 함께 보인다 |
| 소식(블로그) | 업종별 화면 네 개 | 블로그가 없다. 데모의 실제 화면으로 잇는다 |
| 템플릿 목록 | 화면 블록 목록 | 카드를 누르면 데모에서 그 화면이 열린다 |
| 테마 페이지 | 회사 테마 페이지 | 색을 직접 넣을 수 있고 대비 검사 결과와 `pnpm ds:theme` 명령을 보인다 |
| 문서 | `apps/docs`(Starlight) 그대로 | 같은 주소 아래에 묶는다 |
| 플레이그라운드 | 데모(`apps/demo`) | 코드 편집기는 만들지 않았다 |

## 옮기지 않은 것

- 커뮤니티 · 블로그 · 변경 기록 전용 페이지. 저장소가 비공개이고 글이 없다. 변경 기록은 문서 사이트에 있다.
- 검색. 문서 사이트의 검색이 있다.
- 저장소 링크. 공개 전이다(D-50).
