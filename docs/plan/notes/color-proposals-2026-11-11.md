## 1. 범주 식별색 6색 (R-38 · PR-33 · D-145) — 가지에 구현됨

지금 차트 계열을 그대로 범주 색으로 쓰면 두 가지가 모자란다.

- 라이트에서 청록 · 호박 점이 회색 바탕(canvas · sunken) 위 3:1 아래(2.80 · 2.72).
- 6색을 아무 둘이나 같이 놓으면 적색약에서 파랑 ↔ 보라가 ΔE 0.9로 같은 색이 된다(차트는 인접 계열만 검사해서 몰랐다). 6번째로 빨강을 넣으면 위험 · 수입 색과 겹친다.

## 2. 링크와 위험색 (R-43 2 · PR-38 · D-146) — 제안만, 적용 안 함

| | 라이트 | 다크 |
|---|---|---|
| fg.link (brand.600 / brand.400) | #CC3A00, surface 5.03:1 | #FF8867, 7.27:1 |
| status.danger.default (= finance.income) | #C7313A, 5.35:1 | #F67270, 6.12:1 |
| ΔE 링크 ↔ 위험 · 정상 / 적 / 녹 / 청 | 4.7 / 7.1 / 5.9 / 3.3 | 5.8 / 6.9 / 6.4 / 3.6 |

ΔE 5 안팎은 같은 색으로 읽힌다(테마 엔진의 겹침 경고 기준 9).

| 안 | 바꾸는 것 | 측정 | 판단 |
|---|---|---|---|
| a 표 · 목록 안 링크 = 본문 색 | DataGrid 링크 칸 · DataList 제목 · 서랍 링크를 `fg.primary`(굵기 500), 가리키면 밑줄. 토큰 값 변화 없음 | fg.primary ↔ 위험 ΔE 34.0 / 24.7, 대비 14.7 / 12.4 | 추천. 칸 전체가 링크인 열이라 색이 없어도 WCAG 1.4.1 문제 없음 |

## 3. 사이드바 가리킴 · 선택 (R-37 2 · PR-32 · D-147) — 제안만, SideNav 코드 안 고침

지금 값은 brand.900/800이 아니라 회사 색에서 만든 shell 단계다(PR-28). 라이트: 면 shell.800 L 0.328, 가리킴 shell.750 L 0.357, 선택 shell.700 L 0.389.

| 후보 | 선택 면 | ΔE 면↔가리킴 | ΔE 가리킴↔선택 | ΔE 면↔선택 | 선택 글자 대비 | 초점 링 / 선택 면 |
|---|---|---|---|---|---|---|
| 지금 | shell.700 / 다크 shell.800 | 2.8 / 3.3 | 3.3 / 2.8 | 6.1 / 6.0 | 9.7 / 12.4 | brand.500 3.12 / 3.99 |
| N1 밝은 중립 면(추천) | 면에 흰 14% = L 0.436 / 다크 0.388 | 2.8 / 3.3 (가리킴 그대로) | 7.8 / 8.5 | 10.9 / 12.1 | 7.9 / 9.7 | brand.500 2.56 ✗ → brand.400 3.38 / 4.15 |
| N2 회사 색 면 | 면에 brand.400 24% | 2.8 / 3.3 | 7.8 / 9.1 | 11.3 / 13.2 | 8.2 / 9.7 | brand.400 3.49 / 4.13 |

- 가리킴은 지금 값이 이미 옅다(ΔE 3). 문제는 선택이 가리킴보다 한 걸음밖에 안 밝은 것이라, 선택만 밝힌다.
- 추천 N1: 테마 엔진 SHELL_L에 새 단계 `650`(라이트 0.436) · 다크 선택은 `700`(0.389)에 가깝게 — `nav.selected` 라이트 shell.650 · 다크 shell.700, `nav.focus`는 엔진이 이미 대비로 걷는 규칙에 맡기면 brand.400이 된다. 글자 굵기 600 · 흰 아이콘은 그대로. 회사 색이 사이드바에 번지지 않아 차분한 HR 결(PR-27)과 맞는다.
- N2는 회사 색에 따라 갈색 · 남색 면이 되어 회사마다 인상이 크게 달라진다. N3은 가장 또렷하지만 사이드바에서 단추처럼 튄다.
- 넘침 단서: 목록 스크롤 칸 아래 32px를 mask-image로 흐리게(그림의 N1~N3 아래쪽). 끝까지 내리면 흐림을 걷어야 하므로 실제 구현은 `data-overflow-end`(스크롤 이벤트 한 줄) 또는 scroll-driven animation(지원 브라우저만)으로. 다크 사이드바 위 그림자는 보이지 않아 그림자 대신 흐림을 제안한다.
- 그림: sidenav-compare-light.png · sidenav-compare-dark.png(지금 · N1 · N2 · N3, "수요 예측"에 마우스, 대시보드 선택), sidenav-focus-compare-*.png(선택 항목 키보드 초점), cue-crop.png(넘침 흐림 전후).
