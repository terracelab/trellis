The module list comes from `@terracelab/trellis-tokens/modules` (modules.json). Labels, icons and badge types are defined there only, and the sidebar, launcher and notification cards use the same list. The labels in modules.json are Korean. This page shows English names for reference. The tile illustrations are in `@terracelab/trellis-icons/module-tiles`. Insert the sprite once in the document, then use `<use href="#tl-tile-<id>">`.

```ts
import modules from '@terracelab/trellis-tokens/modules';
import { moduleTileSprite, moduleTileByModule } from '@terracelab/trellis-icons/module-tiles';
```
