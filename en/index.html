Principles

Six principles

When two principles conflict, follow the one listed first.

  1. 01Density firstcompact is the default, comfortable is an option
  2. 02Status shows firstcount badges, status colors and approval steps work the same way in every module
  3. 03Korean business conventionsincome is red and expense is blue, five approval states, amounts in won with thousands separators and right-aligned
  4. 04No values outside tokensuse --tl-* variables and Trellis components instead of raw hex, px or font names
  5. 05Same API on every platformweb and native use the names, props and state words of the same contract
  6. 06Accessible by defaulttext contrast of 4.5:1 or more, every action works with the keyboard, the focus ring is always visible, reduced motion is respected

Agents

The docs ship inside the package

Agents read the llms.txt and manifest of the installed version and build screens only from the components and tokens listed there. They request a missing component instead of building it. Button labels and messages follow the bundled copy rules.

Developing with agents

Install, then import three CSS files

Import fonts.css, tokens.css and styles.css in that order. Two html attributes set the theme and density.
